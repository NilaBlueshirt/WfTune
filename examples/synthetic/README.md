# Synthetic analysis fixture

`make_fixture.py` creates deterministic, fabricated monitoring data for trying
WfTune's audit, summary, and plotting workflow without Slurm. These values are
parser fixtures, not benchmark results.

See the [getting started guide](https://github.com/NilaBlueshirt/WfTune/wiki/Getting-Started)
for setup, commands, and fixture scope.
