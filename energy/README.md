# Energy sampling tools

Standalone RAPL/PDU samplers and calibration tools. Use only with site
approval on exclusively reserved nodes; keep credentials and generated data
outside the repository.

See the [energy tools guide](https://github.com/NilaBlueshirt/WfTune/wiki/Energy-Tools)
for setup, calibration, and analysis commands.
