# Manual WfTune runner

A step-by-step alternative to `controller/run_rep.sh` for Nextflow collection,
with separate root and benchmark-user sessions.

See the [manual Nextflow guide](https://github.com/NilaBlueshirt/WfTune/wiki/Manual-Nextflow-Runner)
for the five-command lifecycle, measurement boundaries, operating rules, and
troubleshooting. Complete the
[campaign preparation](https://github.com/NilaBlueshirt/WfTune/wiki/Campaign-Guide)
before collecting data.
